# EggRoll Shop

Full-stack Egg Roll ordering demo built with React, Node.js/Express and MySQL.

## Features
- Product catalog
- Search and category filtering
- Cart management
- Checkout/order creation
- REST API
- MySQL persistence
- Docker Compose ready
- GitHub Actions CI/CD ready

## Local development

Backend:
```bash
cd backend
npm install
npm start
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Docker:
```bash
docker compose up --build
```

This project is a learning/demo application and should be hardened before production use.
